# 🌸 MahiroCraft Launcher

> Современный, лёгкий и эстетичный лаунчер Minecraft на базе **.NET 10 WPF** с нативной поддержкой скинов и глубокой интеграцией Onimai.

### ✨ Ключевые возможности:
- 🎭 **Нативная система скинов Ely.by**: отображение скинов и плащей на любых серверах без необходимости ставить сторонние моды.
- 📦 **Универсальный импорт сборок**: поддержка `.mrpack` (Modrinth) и `.zip` (CurseForge) через обычный Drag-and-Drop в окно лаунчера.
- 🎮 **Discord Rich Presence**: динамический статус с отображением версии, сервера, времени в игре и кнопкой перехода в сообщество.
- 🤖 **Встроенный ИИ-ассистент**: помощь с настройкой сборок и решением ошибок прямо из интерфейса.
- ⏱️ **Playtime Tracker**: точный подсчёт времени, проведённого в каждой сборке.
- ⚡ **Native Performance**: быстрый запуск на .NET 10, векторный UI со скруглениями и аппаратным ускорением.
